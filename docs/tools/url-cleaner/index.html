URL Cleaner

Paste links, get them back without the tracking baggage — utm_*, fbclid, gclid, and 40+ other parameters that exist only to follow you around. One URL per line is fine.

What gets removed

Anything starting with utm_, pk_, piwik_, mtm_, hsa_, or vero_, plus: fbclid, gclid, gclsrc, dclid, gbraid, wbraid, msclkid, yclid, twclid, ttclid, li_fat_id, igshid, igsh, mc_cid, mc_eid, _hsenc, _hsmi, hsCtaTracking, oly_anon_id, oly_enc_id, rb_clickid, s_cid, ml_subscriber, ml_subscriber_hash, _openstat, fb_action_ids, fb_action_types, fb_ref, fb_source, ceid, si (Spotify/YouTube share tracker), _branch_match_id, mkt_tok, trk, trkCampaign, sc_campaign, sc_channel, sc_content, sc_medium, sc_outcome, sc_geo, sc_country. Functional parameters (search queries, page numbers, video timestamps) are left alone.
